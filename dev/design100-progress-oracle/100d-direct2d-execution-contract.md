# Design 100-D: validated direct-2D non-evidence execution contract

This is a fresh one-shot direct-2D run after the retained terminal B and C
infrastructure failures.  It neither alters nor relies on either root, and it
does not open VA, JJ, EVA, optimization, a ladder, package work, or a public
claim.

Before launch, the exact same record writer/reader must round-trip a synthetic
pattern terminal containing four component IDs.  The test must pass before the
new root exists.  The approved calculation is then four serial six-trait
Bernoulli-logit pattern probabilities (`000000`, `010101`, `101010`, `111111`)
using the fixed normalized-standard-normal 5x5 original-`u` rule.  There is one
worker and no retry.

Hard limits are 300 seconds per component and pattern, 60 seconds
stale-progress, 30 seconds liveness, and 1,260 seconds whole-gate.  The sole
exclusive-write root is `/private/tmp/gllvmtmb-design100d-direct2d-output`.
`PROGRESS_COMPLETE` can establish only private record completion for this
finite rule; it is not an exact-reference or approximation-quality result.
