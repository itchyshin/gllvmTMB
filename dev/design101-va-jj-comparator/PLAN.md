# Design 101: private VA/JJ comparator plan

## What is known

Design 100-D supplies a validated four-pattern, fixed-coordinate direct-2D
calculation. It verifies record plumbing and a narrow finite integration rule;
it does not fit global parameters or certify an exact marginal likelihood.

Existing Design 98 specifies the useful four-method factorial:

| Objective | Diagonal posterior | Full posterior |
| --- | --- | --- |
| Direct Gaussian ELBO | QD | QF |
| Jaakkola--Jordan bound | JD | JF |

`EVA` is deliberately excluded: no single objective, posterior family, or
estimand is frozen for that name. It cannot be a fifth comparator by label.

## Symbolic alignment to freeze before execution

For every method, use the same intercept-only six-trait Bernoulli-logit model
with \(u_i\sim N_2(0,I_2)\), \(\eta_{it}=\beta_t+\lambda_t^\top u_i\),
and an explicitly chosen identified loading chart. The comparison measures:

1. optimized method objective (ELBO or JJ bound);
2. shared high-order marginal likelihood at the returned global coordinates;
3. \(\hat\beta\), \(\hat\Lambda\hat\Lambda^\top\), and posterior moments;
4. every failed, timed-out, or non-finite attempt.

The fixture generator, fit objective, common-scale evaluator, and summary must
each expose these same symbols. No method may be called a likelihood merely
because it is evaluated on the common scale.

## Execution gates

1. **Contract gate:** freeze the fixture, parameter chart, starts, tolerances,
   node orders, output root, source hashes, and failure taxonomy.
2. **Pure-logic gate:** fixed-coordinate checks for QD/QF/JD/JF objectives,
   gradients where available, and the common-scale evaluator; no fitting.
3. **Single-fixture gate:** one bounded local run with three fixed starts per
   method, immutable per-attempt records, and no retry.
4. **Adjudication gate:** compare only healthy attempts on the common scale;
   report unavailable contrasts rather than filling them in.
5. **Scale decision:** only if the single-fixture gate is interpretable, ask
   whether a replicated recovery campaign belongs on Totoro or DRAC.

## Replanned executable slice

The maintainer approved execution on 2026-07-24. Design 101 therefore runs
one fresh, local, private six-trait q=2 fixture at a single information level,
three immutable deterministic starts for each of QD, QF, JD, and JF, and one
shared high-order marginal evaluation at every healthy endpoint. The study
terminates after that single fixture: it does not promote itself to a recovery
campaign, and it does not add EVA.

## Approval record

The maintainer approved this fresh private Design-101 manifest and one bounded
non-public execution on 2026-07-24. QD/QF/JD/JF are frozen as the comparison
set; EVA remains deferred. This approval does not authorize an additional
fixture, a recovery campaign, package changes, or a public claim.

## Stop conditions

Stop and report rather than widen scope if an objective is undefined, a chart
is not identified, the common-scale evaluation is unavailable, more than one
method requires an unplanned repair, or the study would need a campaign.
