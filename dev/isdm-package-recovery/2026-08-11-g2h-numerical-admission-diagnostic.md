## Cause classification

`NUMERICAL_TOLERANCE_WITH_UNRELATED_BOUNDARY_GUARD` is the supported diagnosis.

The raw `1e-3` cutoff is defensible as a preregistered *mechanical admission rule*: it prevents a post-hoc declaration of completion. It is not, by itself, a scientific or scale-invariant inference criterion. Here it conflicts with otherwise strong local stationarity evidence, while the diagonal boundary creates an ill-conditioned direction. Crucially, the raw maximum lies in a high-curvature loading coordinate, so the G2h result is neither a loading-ridge diagnosis nor evidence that the G2h profile response is false.

The existing private warm-restart logic was not attempted. Its provenance is `warm_restart_attempted = FALSE`, trigger reason `boundary`; it treats any boundary flag as disqualifying. The only flag is `near_zero_sd_B`, generated by diagonal species 1, despite the largest gradient being `lambda_sp2`. This global boolean guard prevents the existing one-pass same-objective polish from addressing the non-boundary gradient coordinate.

## Single predeclared recommendation

**(2) One narrowly scoped optimizer-control repair, followed by a separately approved replacement smoke.**

Do not relax G2h's `1e-3` cutoff and do not change the fixture, likelihood, parameterisation, profiles, DGP, or campaign criteria. Instead, alter only the private warm-restart eligibility and acceptance logic so one same-objective `nlminb` polish may be attempted when all of the following hold:

1. the initial fit has finite objective, convergence code zero, finite gradient, and `pdHess = TRUE`;
2. `1e-3 < max(abs(gradient)) < 1e-2`;
3. the only boundary is a named near-zero diagonal SD coordinate, and no maximum-gradient coordinate belongs to that boundary coordinate;
4. the candidate preserves the same boundary classification, has non-increasing objective within the existing floating tolerance, retains `pdHess`, and reduces the raw maximum gradient to `<= 1e-3`.

Anything else—including a gradient dominated by the boundary coordinate, a new boundary class, an objective increase, non-PD Hessian, or an unchanged gradient—must retain the original result and `HOLD`.
