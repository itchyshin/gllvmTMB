## Shared figure receipt

Every figure requires a machine-readable provenance sidecar listing source
files/hashes, data version, code commit, figure role, estimand, sample/attempt
denominator, uncertainty treatment, and the gate that authorises its caption.
No figure advances an evidence gate merely because it renders successfully.
