# Terminal pre-fit receipt: source-observation newdata identity

Classification: **BLOCKED / REPRODUCIBLE DEFECT**  
Scope: non-claim-bearing 64-cell public-route feasibility fit  
Source baseline: `1a3b0d161781468a3e647cb9b717eb1635e20730`  
Threads: `OPENBLAS_NUM_THREADS=1`, `OMP_NUM_THREADS=1`

## Outcome

The two-source rank-one SPDE fit converged (`convergence = 0`) with finite
objective 313.6742 in 2.028 seconds. Held-out predictions were finite (72/72),
but the mandatory training-row identity failed:

```text
max |predict(fit, newdata = training)$est - predict(fit)$est| = 1.101235
```

This is not an SPDE projection failure. The random-effect contribution agrees
to floating-point tolerance:

```text
max |(in_sample - in_sample_fixed) - (newdata - newdata_fixed)| = 1.11e-16
```

The fixed component alone differs by 1.101235.

## Root cause trace

The fitted fixed design has nine columns. Rebuilding the ordinary formula with
`model.matrix(delete.response(terms(fit$formula)), training)` returns six and
omits exactly the source-observation columns appended during fitting:

```text
isdm_source:source1:(Intercept)
isdm_source:source1:bias_x
isdm_source:source2:bias_x
```

`predict.gllvmTMB_multi()` constructs `X_new` only from `object$formula` and
passes it to `.gllvmTMB_predict_fixed_eta()`. The formula does not contain the
columns generated by `isdm_source(..., observation = ~ bias_x)`, so the
newdata path silently treats their contributions as zero. The SPDE field is
reconstructed correctly.

## Boundary and next action

No production or qualified pre-run may start while this oracle is red. The
repair belongs in the protected prediction/source-observation API paths and
must wait for the coefficient lease. It needs a focused regression test where
`newdata = training` exactly reproduces eta for a public `isdm_sources()` fit
that uses `isdm_source(observation = ...)`, plus one-source prediction grids
that do not require rows from every declared source.

No shared file was edited and no threshold was changed in response to this
failure.
