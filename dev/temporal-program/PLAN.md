# Native temporal programme: publication and additive source expansion

## GOAL

**Platform:** Codex

Deliver a corrected, cross-platform-verified native temporal covariance provider, then add the four named **additive** temporal-source combinations and individually specified temporal forecasting, direct inference, bootstrap, and selection routes. Each admitted route will have an executable ledger, independent dense Gaussian oracle, lifecycle evidence, user documentation, and its own claim boundary.

**Headline:** repair unconditional temporal simulation before any public or inferential expansion.

**Deferred:** source-by-time interaction kernels; estimated source attenuation with temporal terms; temporal rank above one; temporal slopes; non-Gaussian temporal fits; automatic selection; inferential calibration or coverage claims beyond campaigns that actually pass.

**Discipline:** no source-combination or lifecycle route becomes public merely because parsing or a generic method exists. Long recovery or coverage campaigns are timed first and routed under the compute policy.

## Frozen model meaning

A temporal plus source provider is an additive independent-process model:

\[
V_{ii'}=1_{g_i=g_{i'}}r_T(t_i,t_{i'})[\Sigma_T]_{j_i,j_{i'}}+
K_S(h_i,h_{i'})[\Sigma_S]_{j_i,j_{i'}}+[V_B+V_W+D_\epsilon]_{ii'}.
\]

`r_T` is AR1 with integer gaps or OU with supplied elapsed time. The second
source is one of spatial, phylogenetic, animal, or a fixed labelled kernel. Each
source keeps its existing `indep`, `dep`, or admitted rank-one `latent` trait
mode. Components are independent before observing data.

This is not a separable interaction \(K_S r_T\), an evolving spatial field, or
evolutionarily correlated temporal innovations. Those require another model
contract. The first combined cells fix source `rho = 1`, retain temporal
intercepts, and use Gaussian identity-link ML/Laplace only.

## Acceptance gates

- **G0:** isolated lane, explicit ownership and this frozen contract.
- **G1:** repaired temporal simulation has a deterministic zero-noise state test plus independent dense-moment oracle.
- **G2:** corrected bounded base passes local regression/documentation/package checks and platform-specific CI before merge/release.
- **G3:** each source pair matches independently constructed additive dense covariance and gradients; a product kernel demonstrably differs.
- **G4:** parser/admission/provenance: long/wide, permutation, source labels, series labels, all refused combinations and confounded designs.
- **G5:** source-pair simulation and lossless update/refit; no simulated mean shift.
- **G6:** temporal forecasting matches joint Gaussian conditioning; unsupported extrapolation refuses.
- **G7:** direct interval/profile routes maximize the marginal likelihood, transform correctly and expose boundaries.
- **G8:** bootstrap retains full model/source objects and all refit failures; fixed-seed recovery or coverage campaigns are separately timed and retained.
- **G9:** supplied-candidate selection preserves likelihood semantics and never assigns an invalid LRT distribution at a temporal boundary.
- **G10:** docs, generated help, pkgdown, package checks, validation register, after-task report and plan-versus-result reconciliation agree.

## Compute

Cheap deterministic oracles and smoke fits run locally with one BLAS thread and at most four local cores. Before any recovery or coverage campaign, time one fixture for every source pair and lifecycle route. A retained run projected above 30 minutes requires the measured pre-run evidence and separate compute approval; use Totoro for a bounded rehearsal and DRAC arrays for claim-bearing campaigns.

## Publication sequence

The corrected bounded temporal base may proceed through a dedicated PR, three-OS CI and release decision after G1--G2. Each additional pair or lifecycle route gets a separate release note and validation-register row only after its own gates pass. No source pair or lifecycle route is silently included in the base release.
