# Deferred temporal source-pair tests

These tests are retained as historical development material for prospective
joint temporal--kernel, --phylogenetic, --animal, and --spatial models. They
are deliberately outside `tests/testthat` because the first public temporal
release admits temporal-only covariance. Re-admitting any source pair requires
a new model contract, independent oracle, lifecycle tests, retained recovery
evidence, and a decision to return its tests to the package suite.
