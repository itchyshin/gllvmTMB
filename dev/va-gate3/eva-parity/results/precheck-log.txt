=== STEP 1: documentation (tools::Rd_db, ?gllvm) ===
Usage default (from the `link = ...` line in Usage):
          link = "probit", 

Arguments section entry for `link`:
       link: link function for binomial family if ‘method = "LA"’ and beta 
             family. Options are "logit" and "probit" and "cloglog". 

-> Documentation states the `link` ARGUMENT applies for method='LA' and
   the beta family. It is silent on how VA/EVA choose a binomial link,
   beyond the Usage default value link="probit". This is ambiguous on
   its own, hence the empirical tests below.

=== VERDICT ===
(a) gllvm::gllvm(family = binomial(link = 'logit'), method = 'EVA') IS genuine
    logit-link EVA -- confirmed against an independent glm() anchor with no
    latent confound, and confirmed to diverge appropriately from probit-EVA
    once latent variables are present. A genuine same-link comparison against
    our .eva_fit(..., link = 'logit') is possible.
CAVEAT: the top-level gllvm(..., link = ...) ARGUMENT must NOT be used to
    request this -- it is silently ignored for binomial family regardless of
    method in every configuration tested here. Use family = binomial(link=...).
