## 1. Goal

Four code-review issues from the 3 Oct 2026 sweep found likelihood terms in
`src/gllvmTMB.cpp` that go flat, lose precision or return +-Inf at large
but reachable parameter values. This slice makes each term finite, accurate
and sloped there, following the `gll_dgamma_mean_shape` pattern from #1476:
each CondExp branch is fed its own clamped input, and nothing is `exp()`'d
past about `exp(700)`.

## 2. Implemented

- **#1362 binomial.** The logit/probit ML path forms
  `lchoose + y log p + (n - y) log(1 - p)` from `gll_log_inv_logit` /
  `gll_log_pnorm`. Before, it clamped p to `[1e-12, 1 - 1e-12]` before
  `dbinom()`, and the gradient was exactly 0 beyond |eta| 27.6 / 7.03. The
  multinomial `log(1e-12)` floor on the observed category is removed (named
  in the issue's comments; the log-sum-exp is already finite).
- **#1363 negative binomial.** `gll_dnbinom_mu_size()` and
  `gll_nbinom_log_p0()` replace TMB's `dnbinom_robust`, which forms
  `lgamma(y + n) - lgamma(n)` directly, and the cancelling
  `phi (log phi - log(mu + phi))`. The `size -> Inf` limit is exactly
  Poisson. Used for `truncated_nbinom2` and the siblings `nbinom2`,
  `nbinom1` (size = mu / phi) and `zi_nbinom2`.
- **#1364 Student and beta-binomial.**
  `gll_lgamma_shift(log_x, n) = lgamma(x + n) - lgamma(x) - n log x`, using
  Stirling's series for the difference above x = 50. Student then tends to
  `dnorm` and beta-binomial to `dbinom`, exactly. The R beta-binomial CDF
  behind the residuals had the same defect (`lbeta` difference) and now uses
  the same decomposition.
- **#1386 intercept-slope correlation.** `log(1 - rho^2)` is formed without
  cancellation, and rho is bounded as `(1 - 1e-6) tanh(eta)`, matching the
  temporal AR1 blocks. The closed form alone did not fix the reported
  symptom; see 3a.

## 3a. Decisions and Rejected Alternatives

- **Bound rho, not only the 1 - rho^2 expression (#1386).**
  - Rationale: with the closed form alone, the prior was finite at
    |eta| = 20, but the Laplace inner Hessian was numerically indefinite.
    Measured on a 20-species phylo fit, `fn` was flat to 1e-4 up to
    |eta| = 11, gave a spurious 1.2-unit improvement at 14, and was NaN
    from 16.
  - Rejected: a hard clamp on eta, which would be flat (the #1362
    pathology).
  - Confidence: high. The 1e-6 cap is the file's existing temporal
    convention.
- **Replace `dnbinom_robust` in the NB families as well as the truncated
  log P(0).** #1363's acceptance ("matches the ZT-Poisson limit at
  phi = 1e14") is unreachable while the pmf itself cancels at
  `lgamma(1e14)`. The NB2 / NB1 / zi_nbinom2 siblings share the kernel, so
  they were fixed rather than listed.
- **Fit-changing.** In the ordinary-data comparison (PR body), one trait per
  NB-type / beta-binomial fit sent log phi to 16-32. There the old objective
  was wrong by up to 8.8 units. This is stated as a default change in NEWS
  rather than hidden behind "agrees at ordinary values".

## 5. Tests of the Tests

Every new test was run on the base build and fails there (section 4). Each
one forces its edge value: eta = -30 / 30, phi = 1e14 / exp(800),
df = 1e8 / exp(800), phi_bb = 1e10 / 1e300, atanh_cor = +-20. The phylo test
also asserts that the objective never undercuts the optimum, which catches
the spurious-improvement symptom and not only NaN.
