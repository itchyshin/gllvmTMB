## 1. Goal

#1580 item 1: the auto-suppress note named `indep(0 + trait | ...)` on
fits whose per-row diagonal is the folded Psi of
`latent(..., unique = TRUE)` (or a legacy `unique()` term). Name the
term generically.

## 2. Implemented

The note is built by `.inform_sigma_eps_autosuppress(level_lab, small_eps)`.
It names the grouping and says the per-row diagonal absorbs the residual.
It lists `latent(..., unique = TRUE)` and explicit `indep()` / `unique()`
as the forms that produce that diagonal. It does not interpolate
`indep(0 + trait | <group>)` as if the user wrote it.
