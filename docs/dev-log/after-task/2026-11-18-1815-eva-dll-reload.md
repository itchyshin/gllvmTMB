# After Task: Keep a loaded EVA template when a caller asks to rebuild it

**Branch**: `cursor/fix-1815-eva-dll-unload-7b3a`
**Date**: 2026-11-18
**Roles (engaged)**: Grace, Curie

## 1. Goal

`.eva_load_dll(rebuild = TRUE)` called `dyn.unload` on `gllvmTMB_eva` whenever that DLL was already loaded. That is the same pattern that freed live ADFun pointers and crashed `MakeADFun` for the VA loader (#1803, fixed in #1813).

## 2. Implemented

`.eva_load_dll()` no longer unloads `gllvmTMB_eva`. When that DLL is already loaded from the source-checksum build, `rebuild = TRUE` returns it. When the name is loaded from a different build, the loader stops and asks for a new R session. When the DLL is absent, `rebuild = TRUE` still compiles and loads it.
