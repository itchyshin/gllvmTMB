# confint Wald/vcov alignment + profile -Inf guard (#1959)

## Scope

Issue #1959: on a converged binomial `indep(0 + trait | unit)` fit, `confint()` profile limits disagreed with `tidy()` / `vcov()`, and profile returned `-Inf`.

## Root cause

- **Wald route (`method = "wald"` on fixed effects):** intervals now use `vcov()` column-wise standard errors so `confint()` matches `sqrt(diag(vcov()))` and `tidy(conf.int = TRUE)` on the same link scale.
- **Profile route:** `.confint_wald_targets()` used `diag(sd_report$cov.fixed)[opt$par index]`; replaced with `cov.fixed[i,i]` lookup via `.gllvmTMB_sdreport_se_index()`.
- **`b_fix` profiling index:** removed the unsafe `nrow(td) == length(ix)` fallback that could profile the wrong `b_fix[which]` when free columns and `opt$par` blocks disagree; shared mapping via `.gllvmTMB_b_fix_profile_which()`.
- **Unbounded profile limits:** `.profile_bounds()` asymptotic terminus returns `NA` (not `±Inf`); `confint` finalizer warns with class `gllvmTMB_confint_unbounded` (pattern from open PR #1932, extended to coerce legacy `Inf` to `NA`).
