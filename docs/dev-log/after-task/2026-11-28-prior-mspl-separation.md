# Prior-table and MSPL separation

The prior-table proposal no longer carries the experimental private MSPL multiplier. Its earlier source and validation remain in history for the separate MSPL work. The candidate retains the test that a Gamma unique-variance prior is refused for MSPL fits. This change does not claim that the separate MSPL failure is fixed. The existing shared-table prior limitations and the historical reconciled test evidence remain in force.
