## Plan deviation

The contract predeclared a 45-minute threshold for routing the projected real
run, but it did not predeclare a strict mechanical-gate timeout or sufficient
intermediate progress records for the independent integrations. Applying the
same 45-minute bound to the silent mechanical process was therefore an adaptive
operator stop, not a passed gate or a prospectively timed scientific test. The
stop is retained rather than hidden or converted into a cheaper comparator.

## Durable boundary

Design 99 is terminal and must not be replayed or repaired. A revised
integration strategy, parallel pattern evaluation, progress schema, timeout,
node schedule, fixture, optimizer, or scientific question requires a new
design. The private implementation is research infrastructure, not an admitted
reference and not package code.
