## Scientific gates

- stationary usable fits >= 95%;
- positive-Hessian rate >= 90%, reported separately;
- no unclassified failures;
- standardized fixed-effect bias <= 0.10;
- relative `Sigma_shared` and `Sigma_total` bias <= 0.15;
- `Psi` relative bias <= 0.20, with an absolute rule near zero;
- correlation bias <= 0.10, or <= 0.15 near 0.98;
- large-sample RMSE does not worsen beyond one bootstrap SE;
- catastrophic-but-labelled-healthy exact 95% upper bound < 2%;
- diagnostic sensitivity >= 95% and specificity >= 90%;
- preregistered independent comparator tolerances pass.

Failed cells are repaired under a new immutable campaign ID or removed from
the dependable release claim. They are never pooled with passing cells.
