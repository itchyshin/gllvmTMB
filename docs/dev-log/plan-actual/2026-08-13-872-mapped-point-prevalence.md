# #872-B mapped-point prevalence — plan versus actual

response scales 1 and 5000) were run on Totoro with 12 single-threaded workers.
All rows were retained: 19 executable rows, one objective-evaluation error,
and 16 strictly healthy endpoints. The map identity passed for every executable
pair. The study supplied prevalence evidence but not a calibrated diagnostic:
the decision branch therefore followed the predeclared no-remedy fence rather
than entering package implementation.

The historical issue's 0.197 parameter-distance calculation could not be
reconstructed from the issue or repository history. The actual receipt records
two fully defined replacement distances and explicitly avoids claiming either
reproduces 0.197. No issue state, package code, default, public prose, or
