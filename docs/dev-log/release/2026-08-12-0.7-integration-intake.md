## Decision

The first 0.7 candidate may retain LA-MSPL as an **opt-in experimental
estimator**, but it must distinguish that lane from the ordinary native-Laplace
release claim.  Ordinary-Laplace evidence never promotes LA-MSPL.  Conversely,
the presence of LA-MSPL does not erase the narrow ordinary-Laplace evidence.
The current source is not artifact-current, so a fresh exact-source ladder is
required whichever two-track source boundary is selected.

This is a source-selection HOLD, not a claim that the current package cannot
fit ordinary-Laplace models.  The covered evidence remains narrow: `CRAN07-AA-01`
and `CRAN07-AA-02` (three-trait Gaussian `indep()`/`dep()` point estimation),
with `CRAN07-AA-03` and the named non-Gaussian rows remaining partial.

## Ranked next implementation decision

1. **Retain the two-track source boundary.**  Keep LA-MSPL and the fixed-design
   separation screen in the package as separately bounded opt-in routes.  The
   ordinary native-Laplace claim remains restricted to its covered cells; it
   neither certifies nor suppresses the MSPL programme.
2. **Let the owning MSPL lane adjudicate MSPL.**  It must establish only the
   point-estimation/separation scope it earns, while retaining its explicit
   no-interval/no-likelihood-comparison fences.  This intake does not take
   ownership of its runtime, compiled code, or evidence campaign.
3. **Create an exact two-track source candidate and perform source-clean reconciliation.**
   It must preserve the current public limits, #945 refusal, and all listed
   fences; no research receipt becomes a public capability by merge alone.
4. **Rebuild the artifact/platform ladder for that source identity.**  Only a
   clean tarball and three-OS evidence can support a later 0.7 identity
   decision.
5. **Consider deferred enhancements after the first-release decision.**  #946
   is the first bounded feature candidate, but it is not a release-hygiene
   substitute and must not inherit the old artifact receipt.
